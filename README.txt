fMi Kitchen website - Vercel deployment
1. Extract this ZIP.
2. Open https://vercel.com and sign in.
3. Choose Add New -> Project, or use https://vercel.com/new.
4. Import/upload the extracted project folder (or drag the folder to Vercel's deployment flow if available).
5. Framework preset: Other. Build command: leave blank. Output directory: . (root).
6. Deploy. Vercel gives you a public .vercel.app link to share with customers.

This is a static website; no separate backend is required. Orders are composed in WhatsApp
to +91 96336 48272. The customer must press Send in WhatsApp for the order to reach you.
Edit product names/prices in index.html in the `products` array if needed.
